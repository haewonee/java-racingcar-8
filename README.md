# java-racingcar-precourse

## 구현할 기능 목록

--- 

### 입력
- 사용자로부터 자동차 이름을 입력받는다. (쉼표 기준으로 구분)
- 입력받은 이름이 5자를 초과하는 경우 'IllegalArgumentException' 발생시킨다.
- 사용자로부터 시도할 횟수를 입력받는다.
  - 1 이상의 정수만 허용.
  - 잘못된 입력 시 'IllegalArgumentException' 발생.

### 자동차 기능
- 자동차는 name과 position을 가진다. 
- 0~9 사이의 랜덤값을 생성하여, 4 이상일 경우 position을 1 증가시킨다.

### 게임 진행 
- 입력받은 자동차 이름들로 Car 객체 목록을 생성한다.
- 입력받은 시도 횟수만큼 모든 자동차 로직을 반복 실행한다.

### 출력
- 각 시도가 끝날 때마다, 모든 자동차의 이름과 위치를 출력한다.
- 최종 우승자들을 출력한다. (공동 우승 시 쉼표로 구분)
